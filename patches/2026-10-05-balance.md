# October 5 balance changes

[Sinclair](../heroes/sinclair/sinclair.md) and [Rat King](../heroes/rat-king/rat-king.md)
now use client 6753. Other heroes retain their previous pins. The changes below
are dated October 5 unless explicitly marked October 4. Original wording is in
[the patch notes](raw/2026-10-05.txt).

## Rat King

| Ability / effect | Before | October 5 |
| --- | --- | --- |
| Scrap Grenade damage per shrapnel | 65 | 70 |
| Scrap Grenade tier 2 damage bonus | +65 | +70 |
| Rat Swarm base cooldown | 28s | 24s |
| Rule, Ratannia! base cooldown | 130s | 160s |
| Damage reduction | 20% | 15% |
| Radius | 24m | 20m |
| Charge duration | 12s | 10s |
| Bonus movement speed | 3m/s plus Spirit scaling | 3m/s, no Spirit scaling |
| Tier 1 movement-speed bonus | +1m/s | +2m/s |
| Tier 1 cooldown bonus | -20s | Removed; upgraded cooldown 110s → 160s |
| Tier 2 charge-duration bonus | +8s | Removed; upgraded charge duration 20s → 10s |
| Tier 2 flag-duration bonus | +8s | +5s |
| Tier 3 damage-reduction bonus | +15% | +10%; total 35% → 25% |

The tier-2 +8m radius and tier-3 +150 damage remain. Royal Pestments has no
balance-field change in this patch. Tier bonuses are not final totals.

**Patch-note-only behavior:** Scrap Grenade bounce-targeting bugs were fixed,
and Rule, Ratannia! falls faster while charging. No exact new falling speed or
bounce-targeting algorithm is established by the available fields.

The [October 2 launch snapshot](snapshots/rat-king-2026-10-02.yaml) remains
historical evidence, not current balance values.

## Sinclair

| Effect | Before | October 5 |
| --- | --- | --- |
| Base health regeneration | 2/s | 1/s |
| Bullet damage | 17.76 | 16.5 |
| Gun falloff start/end | 25.4–60.96m | 20–60m |
| Vexing Bolt objective damage | — | Half damage to objectives |
| Rabbit Hex radius | 6.5m | 6m |
| Rabbit Hex tier 3 radius bonus | +3m | +2m |
| Audience Participation copy window | 12s | 9s |
| Copied cooldown percentage | 40% | 60% |

The official notes round the old gun range to 25–61m; the table retains exact
client precision. Vexing Bolt's `BossDamageScale: 0.5` agrees with the objective
damage note, but does not enumerate every valid objective target. Copied
cooldown percentage is not a generic cooldown-reduction stat.

**Patch-note-only for Spectral Assistant:** its gun falloff is also reported as
changing from approximately 25–61m to 20–60m. No separate assistant falloff field
is exposed in the inspected ability record; weapon inheritance is not inferred.

## Troopers

The October 5 notes report a fix for Troopers walking too slowly in lane.
Treat this as announced behavior, not a newly measured walk speed or a complete
movement formula. The configured acceleration changed across the intervening
builds; that alone does not establish the cause of the bug.

## October 4: Street Brawl corrupted items

The separately dated wiki update reports that corrupted items were removed from
Street Brawl. Client 6746 changes the configured corrupted-item round from **5
to 0**. The value change supports the dated report; zero alone is not a general
engine rule. Do not attribute this removal to the October 5 balance patch.

The [corrupted-item sidecar](../data/corrupted-items.yaml) retains historical
client-6726 variant fields; it is not a list of currently obtainable rewards.
The Broker was already configured disabled by October 2, a separate event.

## Boundaries

Source-verified values and announced behavior are not independent runtime tests.
No Baba release, broad item rebalance, new crate rewards or map-coordinate
changes are implied. The root baseline is not advanced wholesale.
