# October 7, 2026 — Source Export and Baba Wording Review

This is a dated comparison of pinned data exports, **not reconstructed official patch notes**. No October 7 Steam gameplay announcement or original raw changelog was found in the reviewed sources. The official forum endpoint returned a verification challenge, so no text was inferred from it.

## Baba

- **Client 6759 export regeneration:** upstream export commit `5799055efcc7a66e45e77da283983da11e00d256` (exporter 1.18.3, published October 7 10:37 UTC) changes the Tier 3 `SilenceDuration` and `SpiritResistReduction` fields for Baba's Brew in both `ability-data` and `ability-cards`: scalar `33.33` becomes `{Value: 1.3333, Multiply: true}`. The embedded game client remains **6759**. This is an export representation correction, not evidence of an October 7 in-game buff or a 33.33-second silence.
- **Client 6762:** the English Feed The Birds description changes “the target” to “the targets” and “the target” to “each target.” The edit clarifies plural wording but does not prove multi-target behavior was newly added.
- **Client 6763:** the reviewed English and gameplay datasets match client 6762. The client version file is dated October 7; its data-repository commit was published October 8 UTC. This timestamp distinction does not make client 6763 the current October 20 game build.
- Baba's [canonical record](../heroes/baba/baba.md) is checked through client 6763. The [October 6 launch snapshot](snapshots/baba-2026-10-06.md) remains separately reconstructible at client 6759, before the export regeneration and wording change.

## Scope and Evidence Limits

The 12 reviewed JSON datasets comprise hero data, meaningful hero stats, ability data/cards, item data/cards, NPC data, generic data, Street Brawl data, convars, misc data and English localization. Across the three checkpoints, gameplay datasets match after the client-6759 export regeneration; the English wording change first appears in 6762 and persists in 6763. The only regenerated-export field changes are the two Baba Brew fields listed above. No change was found in the other reviewed hero, item, NPC, objective, mode or configuration records.

This is limited to those pinned exported datasets, not the complete client or unexported runtime code. It does not prove that no other hotfix occurred. Other heroes, items, map data, map coordinates and the global baseline are not advanced. No raw October 7 changelog is fabricated; the historical raw archive remains at 137 files. Later clients are outside this dated review.
